# 🛏️ فروشگاه کالای خواب

یک فروشگاه اینترنتی ساده و زیبا برای محصولات کالای خواب، نوشته شده با فریمورک Flask و پایگاه داده SQLite.

---

## ✨ ویژگی‌ها

- ثبت‌نام و ورود کاربر
- سبد خرید کامل
- نمایش قیمت به تومان و اعداد فارسی
- طراحی واکنش‌گرا
- پشتیبانی از زبان فارسی و راست‌چین (RTL)

---

## 🛠 تکنولوژی‌ها

- Flask (Python)
- SQLite3
- HTML5 / CSS3
- JavaScript

---

## 🚀 نصب و اجرا

### 1. کلون کردن پروژه

```bash
git clone https://github.com/hamidrezaesh/bedding-store-flask.git
cd bedding-store-flask
```

### 2. ساخت محیط مجازی
ویندوز:
```bash
python -m venv venv
venv\Scripts\activate
```

لینوکس/مک:

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. نصب کتابخانه‌های مورد نیاز
```bash
pip install -r requirements.txt
```

### 4. اجرای برنامه

```bash
python app.py
```

### 5. باز کردن در مرورگر
آدرس زیر را در مرورگر وارد کنید:
```bash
http://127.0.0.1:5000/
```
