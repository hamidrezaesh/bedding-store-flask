## 🛏️ Bedding Store
### [Farsi/فارسی](https://github.com/hamidrezaesh/bedding-store-flask/blob/main/README.FA.md)

A simple and clean Persian e-commerce web application for bedding products, built with Flask and SQLite.

---

## ✨ Features

- User registration & login
- Full shopping cart
- Persian price formatting (Toman)
- Responsive design
- Persian RTL support

---

## 🛠 Technologies

- Flask (Python)
- SQLite3
- HTML5 / CSS3
- JavaScript

---

## 🚀 Installation

### 1. Clone the project

```bash
git clone https://github.com/hamidrezaesh/bedding-store-flask.git
cd bedding-store-flask
```

### 2. Create a virtual environment
Windows:
```bash
python -m venv venv
venv\Scripts\activate
```

Mac/Linux:
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Install the required libraries
```bash
pip install -r requirements.txt
```

### 4. Run the application
```bash
python app.py
```

### 5. Open in browser
Enter the following address in your browser:
```bash
http://127.0.0.1:5000/
```
